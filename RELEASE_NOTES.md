Comic Factory 0.1.0 Beta is an initial Windows/x64 release for supported NVIDIA GPUs.

- Per-user 64-bit installer with Start menu shortcuts and uninstall registration.
- Guided first-time setup for private Python, GPU and emotional-speech environments.
- Version-pinned model downloads, SHA-256 verification and interrupted-download resume.
- Comic storyboards, in-panel speech balloons, separate character voices and emotional delivery instructions.
- Voiced MP4 and subtitle exports; generated artwork remains editable and reviewable.

Requirements: Windows 10/11 x64, NVIDIA Ampere or newer with at least 8 GB VRAM, 24 GB RAM (32 GB recommended), current NVIDIA/Visual C++ runtimes and at least 60 GB free. Expect approximately 20 GB initial downloads. No paid API key is required.

This early beta is unsigned and has been tested locally for packaging, installation, frozen-launcher startup and uninstall preservation. It has not completed a separate clean-PC installation and full-generation test. Story quality, anatomy, balloon positioning and emotional performances can still require review. The MP4 is a voiced comic presentation, not full character animation.

The installer does not contain AI model weights or personal project files. Source code is MIT; third-party models and dependencies retain their respective licenses. Read the README and THIRD_PARTY_NOTICES before distributing a modified build.
