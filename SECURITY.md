# Security and privacy

Do not include credentials or private projects in bug reports. Check logs before sharing them. Setup downloads are version-pinned and verified against SHA-256 hashes; model and archive paths must remain within the chosen data directory. Installed dependencies and downloaded weights remain a third-party supply chain and need maintenance.

Report security issues privately to the repository owner using GitHub's private vulnerability reporting if enabled. Do not post an exploit or a user's private files in a public issue.
